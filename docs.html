SDKs

SDKs

All four cover revisions and promotion, assets, file spaces, capabilities, fan-out groups, apps, studio drafts, architect prompts, and the playground. Each has an Agent Studio walkthrough and an end-to-end test harness.

C#Garrison.Sdk

.NET 8 and .NET 10

dotnet add reference sdk/csharp/Garrison.Sdk/Garrison.Sdk.csproj

C# SDK README

Pythongarrison-sdk

Python 3.9+ with requests

pip install ./sdk/python

Python SDK README

JavaScript and TypeScript@garrison/sdk

Node 18+ and modern browsers; includes an app gateway client

npm run build in sdk/js, then npm install /path/to/sdk/js

JavaScript and TypeScript SDK README

Gogithub.com/jchristn/Garrison/sdk/go

Go 1.21+

a replace directive to sdk/go

Go SDK README

The packages are not published to NuGet, PyPI, or npm yet, and the Go module has no tagged release. Each README shows how to install from your checkout, and scripts/run-sdk-harnesses.sh runs all four test harnesses against a local server and worker.
